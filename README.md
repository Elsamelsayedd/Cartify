# 🛒 Shopping Website

A modern and interactive shopping web application built باستخدام React.js.  
The application allows users to browse products, explore categories, and search for items بسهولة وسرعة.

---

## 🚀 Features

### 🏠 Home Page
- Displays general information about the website.

### 🛍️ Products Section
- Browse a list of products.
- Click on any product to view:
  - Category
  - Description
  - Product image/logo
  - Multiple images (if available)

### 📂 Categories Section
- Browse all available categories.
- Click on a category to view all related products.
- Each product has a detailed view page.

### 🔍 Search Section
- Search for any product بسهولة.
- Displays matching results instantly.
- Click on a product to view full details.

---

## 🧠 How It Works

- The app is built using reusable React components.
- Navigation between pages is handled dynamically.
- Data is fetched from APIs and displayed in a structured way.
- Users can easily move between products, categories, and search results.

---

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- CSS / Tailwind CSS
- API Integration
